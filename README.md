# ARTISTRY 雅芝社群文案合規風險預檢 MVP

這是公開社群美容保養文案的 TFDA 法規風險預檢工具，不比對安麗官網產品說明，也不是安麗／TFDA官方服務或法律最終判定。

## 啟動與測試

需要 Node.js 22 或以上，不需安裝套件、API金鑰或資料庫服務。

Windows可雙擊 `Start-MVP.cmd`，再開啟下方本機網址；保持啟動視窗開啟。此電腦也可使用Codex內附的Node執行環境。其他系統請使用以下命令。

```sh
node server.mjs
```

在瀏覽器開啟 http://127.0.0.1:4173 。同一區域網路的其他裝置可使用這台電腦的區域網路 IP 加上 `:4173` 開啟。請勿直接雙擊 HTML，瀏覽器會阻擋本地模組與JSON載入。若要讓網際網路上的任何人公開使用，請將 `dist/` 部署到已授權的靜態網站主機，並設定正式網域與 HTTPS。

```sh
node --test tests/engine.test.mjs
node --check dist/engine.js
node --check dist/app.js
```

## 已完成

- 公開社群文案（不需選平台）、三組試填範例、四級風險與逐句法規來源。
- 分句、原文起迄位置、整句語境保存；數字、期間與功效關聯判讀。
- 受控法規風險詞庫與語境判讀；不輸出品牌官方宣稱相符結果。
- 獨立法規規則、逐條依據、保守處理已知否定語境與跨分句風險。
- 圖片選取、預覽、格式／大小限制、待OCR資料結構。圖片存在時最低顯示「注意」且明確標示未分析。
- JSON報告下載，包含資料與引擎版本、來源版本、SHA-256及引用。
- 政府現行法規、附件與歷史資料分離；原始下載快照。安麗來源僅保留在舊版資料庫檔案，不參與本介面判讀。

## 架構與檔案

| 檔案 | 功能 |
| --- | --- |
| `dist/index.html`、`style.css`、`app.js` | 繁體中文響應式介面；資料輸入與安全文字渲染 |
| `dist/engine.js` | 純函式分析核心，可另接後端或OCR服務 |
| `dist/data/seed.json` | Product / OfficialClaim / Evidence / Source / Version / TFDARule / LegalReference |
| `dist/data/historical.json` | 已停止適用的詞句資料索引，不參與評分 |
| `docs/models.ts` | 資料模型、欄位型別與報告契約 |
| `sources/` | 14份官方來源快照及擷取清單，僅供來源稽核，未放入網站公開資產 |
| `tests/engine.test.mjs` | 功效、時間、程度、否定、來源完整性、歷史隔離與圖片狀態測試 |
| `server.mjs` | 零相依靜態伺服器，預設監聽所有網路介面 |

流程：文案 → 分句及保留上下文 → 現行法規風險規則 → 合併最高級別 → 附單一法規來源。統一以公開社群發文情境預檢。

## 分級與限制

四級為產品設計，不是TFDA法定等級：低＝已收錄原句且未命中較高風險；注意＝語意相關、資料範圍不足、單獨時間或圖片未分析；中度＝量化功效佐證未確認或絕對化程度；高＝可能涉及醫療、生理或結構作用。採最高命中級別，不取平均。

本版採**受控語意詞庫**，不是LLM、向量模型或完整自然語言理解。能比對部分同義外觀描述、追蹤期間／程度延伸，但對未收錄語彙、反諷、引述、複雜否定、跨段因果可能誤判或漏判。未找到官方說法只代表本次收錄未找到；低風險不是合法保證。未自行上網對每次輸入即時查核。

5倍與7次宣稱保留條件及evidence缺口。未取得完整試驗報告、比較對象、樣本數與12週結果，欄位保留null。**官方行銷文字不是已驗證的試驗證據**。本MVP不捏造佐證。建議稿只使用已收錄官方描述，並非自動核准。

圖片最多4張、每張10MB，僅支援JPEG／PNG／WebP，存在瀏覽器記憶體，不上傳至伺服器、不寫入資料庫。另有兩張圖片的前後對照工具：可拖動分界滑桿，並以64×64縮圖像素差異提供檢視指標。差異比例只表示影像像素不同，不代表功效、醫療效果、前後拍攝條件一致或法規結論。重新整理即清除文案、圖片與對照。OCR、視覺語意與圖片中的文字仍需人工確認。

## 更新規則

新增來源須核對官方網域並保存新的不可變快照、hash與Source版本；不可覆蓋舊版本。人工核對原文、產品歸屬、註解、證據與法規效力後，再新增Claim／Evidence／Rule版本，透過supersedes串接舊版並更新dataset_version。舊版報告保留版本，不能用新規則悄悄改寫既有結果。

本版只含首次快照，尚未實作排程同步、歷史差異介面、登入、雲端文案保存、OCR、圖片比較或全系列匯入。

標示法源另保存[正式公告](https://www.fda.gov.tw/TC/newsContent.aspx?cid=3&id=25259)與條文（2021-07-01生效）。查到的[2025修正預告](https://www.fda.gov.tw/tc/newsContent.aspx?cid=4&id=t623380)以draft保存，不宣稱草案已生效；正式上線包裝稽核前須再次確認後續公告。
